Fix the notification system: wire up event listeners, connect to storage, show honest state.

**Research finding:** The notification dropdown (index.html lines 210-234) is pure static HTML. No code populates `#notifications-list`. The `#mark-all-read` button has no listener. The profile toggle has no listener. STRM-03 was "data infrastructure only" — there may be no actual notification documents in Firestore yet.

**Approach: Build a minimal but honest notification system using localStorage for now.**

1. **Wire #mark-all-read button** in the inline script or in a new notifications init function:
   ```javascript
   document.getElementById('mark-all-read')?.addEventListener('click', () => {
     const items = document.querySelectorAll('#notifications-list .notification-item');
     items.forEach(item => item.classList.remove('unread'));
     // Update badge
     const badge = document.querySelector('.notification-badge');
     if (badge) badge.style.display = 'none';
     // Save to localStorage
     localStorage.setItem('lumi_notifications_read', Date.now().toString());
   });
   ```

2. **Wire #profile-notifications-toggle** in profile.js or inline script:
   ```javascript
   const notifToggle = document.getElementById('profile-notifications-toggle');
   if (notifToggle) {
     // Load saved preference
     notifToggle.checked = localStorage.getItem('lumi_notifications_enabled') !== 'false';
     notifToggle.addEventListener('change', (e) => {
       localStorage.setItem('lumi_notifications_enabled', e.target.checked.toString());
     });
   }
   ```

3. **Populate notification list with honest state.** Check if Firestore has a notifications collection for the current user. If implementing a Firestore listener is too complex for this phase:
   - Show a clean empty state: replace the static "Bildirim bulunmuyor" placeholder with a properly styled empty state:
     ```html
     <div class="notification-empty">
       <p>Henuz bildirim yok</p>
       <p class="notification-hint">Izleme listenizdeki iceriklerin yayinlanma bildirimleri burada gorunecek.</p>
     </div>
     ```
     (Use proper Turkish characters: Henuz -> Henuz with u-umlaut, etc.: Henüz bildirim yok, İzleme listeniz)
   - If a Firestore `/users/{uid}/notifications` collection exists and has documents, add a simple listener to populate the list. But do NOT build a full notification backend — that's Phase 4 territory.

4. **Ensure notification dropdown toggle works.** The bell icon in the header should toggle `#notification-dropdown` visibility. Verify this click handler exists and works on mobile (touch events).

5. **Style the empty state** — add CSS for `.notification-empty` and `.notification-hint` if not already present. Keep it minimal: centered text, muted color for hint.
