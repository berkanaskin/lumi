# Phase 03.1 Plan 02: Detail Modal Visual Bug Fixes Summary

**One-liner:** Fixed three detail modal bugs — removed stuck shimmer skeleton, filled mobile viewport top-to-top, and replaced "Turkey" with locale-appropriate "Türkiye" everywhere.

## Tasks Completed

### Task 1: Remove stuck shimmer + fix modal top gap (BUG-04, BUG-05)

**Commit:** `4401f96`

**BUG-04 — Stuck ratings shimmer:**
- `buildRatingsHTML()` in `src/features/detail.js` previously returned `'<div class="ratings-skeleton"></div>'` when `allRatings` was null/undefined — which happened permanently when OMDb found no data
- Changed to return `''` (empty string) — clean state, no shimmer when no ratings available
- The skeleton div in `buildStreamingHTML()` was left intact — it still shows during streaming data loading (valid transient state)

**BUG-05 — Modal top gap on mobile:**
- Mobile CSS used `height: 100%; max-height: 100vh` but the parent `.modal-backdrop` uses `align-items: center`, so the modal was vertically centered leaving a gap at the top
- Changed mobile `@media (max-width: 767px)` rule to use `position: fixed; inset: 0` — modal now fills the entire viewport edge-to-edge
- Removed `border-radius` on mobile (was `var(--radius-lg) var(--radius-lg) 0 0`) so no rounded corners cause gap at top
- Desktop styles unchanged

### Task 2: Fix country name display (BUG-06)

**Commit:** `916b629`

Changes made across 5 files:

1. **`src/lib/state.js`** — Default `countryName` changed from `'Turkey'` to `'Türkiye'`

2. **`src/services/api.js`** — `GeoIPService.detectCountry()` now converts the English country name returned by ipapi.co into a Turkish locale name using `Intl.DisplayNames(['tr'], { type: 'region' })`. Fallback map covers common countries with proper Turkish names (Türkiye, ABD, Birleşik Krallık, etc.)

3. **`src/main.js`** — When reading saved country from localStorage (which may have old 'Turkey' string), the code now re-derives the display name from the stored country code via `Intl.DisplayNames` — this retroactively fixes old sessions without clearing user data

4. **`api/geoip.js`** — Edge function fallback response changed from `'Turkey'` to `'Türkiye'`

5. **`index.html`** — All 14 country dropdown `data-name` attributes updated from English names to Turkish locale names (e.g., `data-name="Turkey"` → `data-name="Türkiye"`, `data-name="United States"` → `data-name="ABD"`) — these are stored in state when user selects a country from the dropdown
