**BUG-04 — Stuck shimmer strip:**

1. In `src/features/detail.js`, find `buildRatingsHTML(tmdbScore, allRatings)` (around line 607-608).

2. The current code returns `'<div class="ratings-skeleton"></div>'` when `allRatings` is null/undefined. This skeleton never gets replaced if no IMDB ID is found (OMDb returns nothing).

3. Change the logic: when `allRatings` is falsy, return an empty string `''` instead of the skeleton. The skeleton should ONLY be shown during the initial loading window, not as a permanent placeholder.

**BUG-05 — Detail modal top gap:**

6. In `src/styles/modals.css`, find the mobile media query (around line 49) that styles `.modal-content` or `.modal`.

7. The current mobile styles use `height: 100%`, `max-height: 100vh` but the parent `.modal-backdrop` uses `align-items: center` which vertically centers the modal, creating a visible gap at top.

8. For the mobile breakpoint, change the modal positioning to fill the entire viewport:
   ```css
   @media (max-width: 768px) {
     .modal-content {
       position: fixed;
       inset: 0;
       border-radius: 0;
       max-height: none;
       height: 100%;
       width: 100%;
       z-index: 1001;
     }
   }
   ```
   OR set `.modal-backdrop` to use `align-items: stretch` on mobile instead of `center`.

9. Ensure the modal's own close (X) button and header remain visible and functional at the very top of the viewport. The X button should be at `top: 12px; right: 12px` or similar.

10. Since Lumi is mobile-only (desktop cancelled), these mobile styles can be the default without a media query. But keep the media query if it already exists to avoid regressions in case someone opens on a larger screen.
