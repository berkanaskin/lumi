## What Was Done

### Task 1: Wire notification system (BUG-07)

The notification dropdown was pure static HTML with no JavaScript handlers. Fixed:

- Added `click` event listener on `#mark-all-read` button — removes `.unread` class from all notification items, hides badge, persists timestamp to `localStorage.lumi_notifications_read`
- Added `change` event listener on `#profile-notifications-toggle` — saves boolean preference to `localStorage.lumi_notifications_enabled`
- On init, loads saved preference (defaults to `true`/enabled if never set)
- The existing `.dropdown-empty` empty state in the notifications list was already properly styled — retained as-is

### Task 2: Search overlay i18n + evaluation (BUG-10)

Filter chips in the search overlay had hardcoded English labels ("All", "Movies", "TV Shows", "People"). Fixed:

- Updated all 4 filter chip buttons in `index.html` to use `data-i18n` attributes with Turkish as default text content
- Added `filter_all`, `filter_movies`, `filter_tv_shows`, `filter_people` keys to both Turkish (TR) and English (EN) translation objects in `public/i18n.js`
- The existing i18n `setLanguage()` function already applies `data-i18n` attributes to DOM elements — no new wiring needed
- Search overlay kept (not removed) — serves as complement to autocomplete for full result browsing with filters
