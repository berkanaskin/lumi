## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | #050505 (dark) / #f8f9fa (light) | Background, void surface, page container |
| Secondary (30%) | #0a0a0f (dark) / #ffffff (light) | Cards, elevated surfaces, modals |
| Accent (10%) | #5858f3 (primary purple/blue) | CTA buttons, active states, brand highlights |

- Primary call-to-action buttons (sign up, save to watchlist, add to favorites)

- Toggle switches (on state)

- Notification icons (success, info)

## Component Interactions

### Page Transitions
- **Animation:** Fade + slide (300ms)
- **Method:** CSS View Transitions API (baseline Firefox 144, Oct 2025) or fallback to CSS fade
- **Path:** Navigation between discover, search, detail, profile pages via `src/lib/navigation.js`

### Card Hover (Movie Cards - Desktop)
- **Action:** Hover over movie card triggers overlay reveal
- **Visual:** Scale card 1.05x + reveal gradient overlay with title + metadata
- **Animation:** 300ms ease
- **Mobile:** No hover — tap to open detail modal instead

### Modal Overlay (Detail Page)
- **Pattern:** Letterboxd-style modal overlay (keep existing pattern)
- **Backdrop:** Glassmorphism blur (20px backdrop-filter) with semi-transparent dark overlay
- **Close:** Tap/click outside modal, or explicit close button
- **Animation:** Fade in 300ms, fade out 300ms

### Loading Spinner
- **Design:** Lumi-branded custom spinner (CSS-based, no external image dependencies)
- **Color:** Primary accent (#5858f3) rotating indicator
- **Size:** 40px × 40px default (scale as needed)
- **Animation:** Continuous 1.2s rotation (linear)
- **Source:** Replace existing loading states in `src/ui/loading.js`

### Toast Notifications
- **Position:** Top center of viewport (fixed positioning, 16px from top)
- **Style:** Glassmorphism panel (backdrop blur + semi-transparent background)
- **Animation:** Slide down 300ms on show, slide up 300ms on hide
- **Duration:** Auto-dismiss after 3 seconds (user can dismiss manually)
- **Color:** Use semantic colors (success green, error red, info blue)
- **Source:** Refactor existing `src/ui/toast.js` to top-sliding pattern

### Navigation Structure
- **Desktop:** Sidebar (left, fixed or sticky) with navigation items + logo
- **Mobile:** Bottom nav bar (fixed at bottom, safe-area-inset-bottom respect for notched devices)
- **Active indicator:** Accent color (#5858f3) for active page
- **Interaction:** Click to navigate, Material Design ripple effect on tap

### Theme Toggle
- **Trigger:** Button in header (icon: sun/moon via Material Symbols)
- **Behavior:** Click toggles between dark/light, saves preference in localStorage
- **Animation:** 300ms smooth color transition across entire page

### Responsive Breakpoints
- **Mobile:** < 768px (single column layouts, bottom nav, 1-2 poster columns)
- **Tablet:** 768px – 1024px (grid layouts, sidebar becomes collapsible)
- **Desktop:** ≥ 1024px (multi-column grids, persistent sidebar, 4+ poster columns)
- **Implementation:** CSS Grid `auto-fit / minmax()` with `clamp()` function (no explicit breakpoints where possible)

## Layout Grids

### Movie Card Grid (Poster-Heavy)
```
Mobile: 2 columns × N rows
Tablet: 3 columns × N rows
Desktop: 4-5 columns × N rows

Grid gap: var(--space-md) = 16px
Card aspect ratio: 2:3 (poster dimensions)
```

### Discover Page Hero Banner
```
Full width, height: 300-400px on mobile, 500px+ on desktop
Content: Daily AI recommendation (title, genre, description, CTA)
Background: Poster backdrop blur + gradient overlay (cinematic effect)
```

### Search Results Layout
- **Film Search:** Grid of cards (same as discover)
- **AI Search:** List layout with card preview + metadata (distinct visual treatment to differentiate from film search)

### Detail Modal
```
Mobile: Full screen overlay (safe area top + bottom)
Desktop: Centered modal (max-width: 800px, scrollable content)
Content: Poster (left), title + metadata (right) on desktop; stacked on mobile
```

## Accessibility & Inclusive Design

| Requirement | Implementation |
|-------------|-----------------|
| Color contrast | All text meets WCAG AA (4.5:1 for body, 3:1 for large text) |
| Touch targets | Minimum 44px × 44px (Material Design standard) |
| Keyboard navigation | Tab order through nav, buttons, form inputs; arrow keys for carousel if used |
| Focus indicators | Visible focus ring (accent color, 2px border) on all interactive elements |
| Icon labeling | All Material Symbols icons paired with visible text or `aria-label` |
| Alt text | All poster images have alt text (movie title + year) |
| Reduced motion | Respect `prefers-reduced-motion` media query; skip animations if requested |
| Language support | English and Turkish (i18n.js, Turkish "I" character safety built-in) |
