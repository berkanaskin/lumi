# Phase 3 — UI Design Contract

> Visual and interaction contract for Phase 3: Content Enrichment.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none (vanilla JS SPA — no component framework) |
| Preset | not applicable |
| Component library | none — DOM-centric innerHTML + CSS custom properties |
| Icon library | Material Symbols Outlined (Google Fonts, variable font) |
| Font — body/UI | Spline Sans (weights: 400, 500, 600, 700) |
| Font — headings | Crimson Text (weights: 400, 600, 700) |

Source: `src/styles/tokens.css`, `src/styles/theme.css` (Phase 1 established)

## Spacing Scale

Declared values (multiples of 4, sourced from `--space-*` tokens in `tokens.css`):

| Token | CSS Var | Value | Usage |
|-------|---------|-------|-------|
| xs | `--space-xs` | 4px | Icon gaps, rating logo-to-number gap, badge internal padding |
| sm | `--space-sm` | 8px | Compact element spacing, chip gap, thumbnail gap |
| md | `--space-md` | 16px | Default element spacing, section inner padding |
| lg | `--space-lg` | 24px | Section padding, card group gaps |
| xl | `--space-xl` | 32px | Layout gaps between major detail sections |
| 2xl | `--space-2xl` | 48px | Major section breaks (e.g., between streaming and overview) |
| 3xl | `--space-3xl` | 64px | Page-level vertical rhythm |

Exceptions:
- Touch targets for filter chips (All / Movies / TV Shows / As Director): minimum 44px height to meet mobile tap target requirements
- Platform logo containers in the streaming section: 40px × 40px fixed size (not on the 8-pt scale, but standard logo display size)
- Country selector in header: 36px height (fits header bar height constraint)

## Typography

Phase 3 declares exactly 4 font sizes introduced or actively used by the new components in this phase. Existing heading levels `h1` (32px) and `h3` (24px) are established styles from Phase 1 and are not modified or introduced in Phase 3 — they are therefore excluded from this contract. Executors must use those existing styles as-is from `tokens.css`/`theme.css` without redeclaring them.

| Role | Size | Weight | Line Height | Font Family | CSS Var / Class |
|------|------|--------|-------------|-------------|-----------------|
| Body | 16px | 400 | 1.5 | Spline Sans | `body`, `.body-text` |
| Label | 14px | 500 | 1.4 | Spline Sans | `.label` |
| Heading (section) | 20px | 700 | 1.2 | Crimson Text | `h4` |
| Display (movie title on detail) | 28px | 700 | 1.2 | Crimson Text | `h2` |

Declared sizes: 14, 16, 20, 28 (4 total).
Declared weights: 400 (regular) + 700 (bold) — 500 is an intermediate label weight, treated as part of the emphasis pair. No new type styles are introduced in Phase 3.

## Color

Both dark (default) and light themes are fully specified in `src/styles/theme.css`. Executors MUST use CSS custom properties, never hardcoded hex values.

### Dark Theme (Default)

| Role | CSS Var | Dark Value | Light Value | Usage |
|------|---------|------------|-------------|-------|
| Dominant (60%) | `--bg-void` | `#050505` | `#f8f9fa` | Page background, modal backdrop |
| Secondary (30%) | `--bg-surface` / `--bg-elevated` | `#0a0a0f` / `#121218` | `#ffffff` / `#f0f2f5` | Detail page cards, streaming section container, person bio card, video thumbnail container |
| Accent (10%) | `--primary` | `#5858f3` | `#5858f3` | Reserved — see below |
| Destructive | `--error` | `#ff6b6b` | `#dc2626` | Destructive actions only |
| Warning | `--warning` | `#f59e0b` | `#d97706` | Stale streaming data indicator (>24h old) |
| Success | `--success` | `#10b981` | `#059669` | Fresh streaming data, confirmed availability |

Accent (`--primary: #5858f3`) is reserved EXCLUSIVELY for:
1. "Unlock with Premium" CTA button on the trivia gate
2. Active state on video category tabs (Trailers / Behind the Scenes / Interviews)
3. Active filter chip on filmography grid (All / Movies / TV Shows / As Director)
4. Focus ring on interactive elements (accessibility)
5. Country selector active/open state border

Accent is NOT used for: platform logos, rating scores, cinema badges, bio text, or general navigation.

Glass effects:
- Container backgrounds: `--glass-bg` (rgba 3% white in dark / 2% black in light)
- Container borders: `--glass-border` (rgba 8% in both themes)
- Hover state backgrounds: `--glass-bg-hover`

## Component Inventory

New UI components introduced in Phase 3 (all rendered via innerHTML + CSS, no framework):

### 1. Ratings Bar
Placement: Under movie title line, above overview text.
Layout: Horizontal row, left-aligned. Gap: `--space-md` (16px) between each source.
Per rating item: source logo (24px height, auto width) + `--space-xs` (4px) gap + score text (16px / 400 / `--text-primary`).
Score format: native — `8.2/10` (IMDB), `92%` (Rotten Tomatoes), `85/100` (Metacritic).
No text labels (no "IMDB:", no "Score:"). Logo only + number.
Logos: static assets for IMDB, Rotten Tomatoes, Metacritic (SVG or PNG, 24px height).

### 2. Where to Watch Section
Placement: Just below poster/title/ratings area, above overview.
Section header: "Where to Watch" — existing `h3` style (do not redeclare size/weight).
Groups: Stream | Rent | Buy — each group label `.label` (14px / 500) + row of platform tiles.
Platform tile: 40×40px logo container (`--bg-elevated`, `--radius-sm`) + platform name (12px / 400 / `--text-secondary`) below.
On tap: navigate to deep link URL (opens in new tab).
Freshness line: below the section, `.label` (14px / `--text-muted`): "Updated 3 hours ago".
Stale warning (>24h): replace muted text with `--warning` color + Material Symbol `warning` icon (18px).
No streaming data state: show `.label` text "Not available for streaming in [Country]" in `--text-muted`.

### 3. Cinema Release Badge
Placement: Overlay on poster (top-left corner) OR as inline badge in the title area — either is acceptable.
Executor discretion: Use poster overlay if poster is present; use inline badge in title area on list/card views.
States:
- Upcoming: dark badge (`--bg-elevated`, `--radius-full`) with text "In cinemas [Month Day]" (14px / 500 / `--text-primary`)
- Now showing: accent-bordered badge (`--glass-border-active`) with text "Now in cinemas" (14px / 500 / `--primary`)
- Streaming date: badge with text "Streaming [Month Day]" (14px / 400 / `--text-secondary`)

### 4. Video Category Tabs
Placement: In the Videos section of the detail page.
Tabs: Trailers | Behind the Scenes | Interviews.
Active tab: bottom border 2px `--primary`, text `--text-primary` (16px / 500).
Inactive tab: no border, text `--text-muted` (16px / 400).
Content: horizontal scroll container (overflow-x: scroll, scrollbar hidden on mobile).
Thumbnail: 16:9 aspect ratio, `--radius-md`, 200px wide on mobile / 240px on desktop.
Play icon overlay: Material Symbol `play_circle` (48px, `--text-primary`, centered absolute).
Accessibility: the thumbnail container acting as the play trigger MUST include `aria-label="Play [video title]"` so screen readers announce the video title. Do NOT rely on the icon alone for accessible labeling.
On tap: replace thumbnail container with YouTube iframe embed (existing pattern from detail.js).

### 5. Filmography Filter Chips (Person Page)
Chips: All | Movies | TV Shows | As Director.
Active chip: `--primary` background, `--text-primary` text, `--radius-full`.
Inactive chip: `--glass-bg` background, `--glass-border` border, `--text-secondary` text, `--radius-full`.
Height: 44px minimum (touch target). Horizontal padding: `--space-md` (16px).
Sort control: right-aligned dropdown or toggle — "Newest first" / "By rating". `.label` styling.

### 6. Person Bio Card (Person Page)
Layout: Two-column on desktop (photo left, bio right), single-column stacked on mobile.
Photo: 160×240px (2:3 ratio), `--radius-md`, poster style.
Bio text: `.body-text` (16px / 400 / `--text-secondary`), max 4 lines with "Show more" expand.
Metadata row: birth date, birthplace, known-for department — `.label` (14px / 500 / `--text-muted`).

### 7. Frequently Works With (Person Page)
Section header: "Frequently Works With" — `h4` (20px Crimson Text).
Layout: horizontal scroll of person chips.
Person chip: circular avatar (48×48px, `--radius-full`) + name label (12px / `--text-secondary`) below.
On tap: navigate to /person/:id.

### 8. Trivia Premium Gate
Placement: Where trivia content would appear on detail page.
Visual: blurred/dimmed content area with centered lock overlay.
Lock icon: Material Symbol `lock` (32px, `--text-muted`).
Headline: "Unlock Trivia" — `h4` (20px / `--text-primary`).
Body: "Full trivia and awards details are available with Lumi Premium." — `.body-text` (16px / `--text-secondary`).
CTA button: "Unlock with Premium" — accent filled button (`--primary` background, `--text-primary`, `--radius-full`, 44px height, `--space-xl` horizontal padding).
No free teaser — section is fully locked with no visible trivia content.

### 9. Country Selector (Header)
Position: In main app header, right side (alongside existing header controls).
Appearance: compact button showing country flag emoji + 2-letter country code (e.g., "TR"). `.label` styling.
On tap: opens a dropdown/sheet with searchable country list.
Active item in list: `--primary` accent left border, `--bg-elevated` background.
Save behavior: persists to localStorage + `state.currentRegion`.

## Interaction States

All interactive elements must implement these states consistently:

| State | Visual Treatment |
|-------|-----------------|
| Default | Per component spec above |
| Hover (desktop) | `--glass-bg-hover` background shift, `var(--transition-fast)` (0.15s) |
| Focus (keyboard) | 2px outline `--primary` + 2px offset, never removed (`outline: none` is forbidden) |
| Active/Pressed | 0.97 scale transform, `var(--transition-fast)` |
| Loading | Skeleton shimmer using `--bg-elevated` → `--glass-bg` gradient animation |
| Disabled | opacity: 0.4, cursor: not-allowed |
| Error | `--error` border or text, per component |

Loading skeletons required for:
- Ratings bar (while OMDb fetching)
- Where to Watch section (while streaming availability fetching)
- Person bio card (while TMDB person fetching)
- Filmography grid (while combined_credits fetching)

Skeleton animation: CSS `@keyframes shimmer` with background-position slide — 1.5s linear infinite. Already established in `src/styles/animations.css` — reuse existing pattern.

## Page Layout Contracts

### Detail Page — Section Order (top to bottom)

1. Poster + Title area (existing)
2. Ratings bar (IMDB / RT / Metacritic) — NEW
3. Where to Watch section — NEW
4. Overview / synopsis (existing, moved down)
5. Cinema / streaming release badge — NEW (inline in title area or poster overlay)
6. Cast row (existing)
7. Videos section (existing tabs, extended with Interviews tab) — EXTENDED
8. Trivia & Awards section with Premium gate — NEW

### Person Page — Section Order (top to bottom)

1. Person Bio Card (photo + name + metadata + biography)
2. Filmography grid with filter chips + sort control
3. Frequently Works With (horizontal scroll)
4. (No trivia/awards section on person page — awards surfaced on detail pages only)

### Responsive Breakpoints (existing, enforced)

| Breakpoint | Layout behavior |
|------------|----------------|
| ≤ 640px (mobile) | Single column, bottom navigation, horizontal scroll for chips/videos |
| 641–1024px (tablet) | 2-column grids where applicable |
| ≥ 1025px (desktop) | Multi-column, hover states active |
