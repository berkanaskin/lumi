- `export const config = { runtime: 'edge' };`
- Accept query params: `imdbId` (required), `country` (default 'tr')
- Lowercase the country param before sending to API
- Call `https://streaming-availability.p.rapidapi.com/shows/${imdbId}` with query `?country=${country}&series_granularity=show`
- Headers: `X-RapidAPI-Key: process.env.RAPIDAPI_KEY`, `X-RapidAPI-Host: streaming-availability.p.rapidapi.com`
- Extract `data.streamingOptions[country]` array from response
- Return JSON `{ options: [...], fetchedAt: Date.now() }` with status 200
- Return `{ error: 'Missing imdbId' }` with 400 if no imdbId
- Return `{ error: 'Streaming lookup failed' }` with 500 on fetch error
- Include `Access-Control-Allow-Origin: *` and `Content-Type: application/json` headers

**api/omdb.js:**
- Accept query param: `imdbId` (required)
- Call `https://www.omdbapi.com/?i=${imdbId}&apikey=${process.env.OMDB_API_KEY}`
- Return the full OMDb JSON response (contains Ratings array, Awards string, imdbRating, Metascore)
- Return `{ error: 'Missing imdbId' }` with 400 if no imdbId
- Return `{ error: 'OMDb lookup failed' }` with 500 on error
- Include same CORS headers

**api/geoip.js:**
- No query params needed
- Call `https://ipapi.co/json/` (free HTTPS, no API key)
- Extract `country_code` and `country_name` from response
- Return JSON `{ countryCode: data.country_code, countryName: data.country_name }`
- Return `{ countryCode: 'TR', countryName: 'Turkey' }` as fallback on error (safe default)
- Include same CORS headers

- Collection: `streamingAvailability`, doc ID: `${tmdbId}_${country.toUpperCase()}`
- Cache check: if doc exists and `fetchedAt` is within 24h, return cached data
- On cache miss or stale: call `/api/streaming-availability?imdbId=${imdbId}&country=${country.toLowerCase()}`

- Export `getStreamingWithCache` and `GROUP_MAP`
