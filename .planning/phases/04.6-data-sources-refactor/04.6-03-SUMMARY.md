# Phase 4.6 Plan 03: Onboarding Hybrid Auto-Detect + 6→4 Slide Refactor Summary

Reduced onboarding friction from 6 cinematic slides to 4 by folding the dedicated Language (S2) + Country (S3) slides into a single confirmable detection banner on S1, opening a bottom-sheet picker for overrides. Also fixed the S4 Ready CTA tap-isolation bug: only the explicit "Discover Lumi" button advances; confetti taps, curtain overlays, and slide body touches are blocked via CTA-scoped listener + CSS pointer-events defense.

## Final slide enum

```
0 WELCOME    (banner + wordmark + poster trio + value props + Continue CTA)
1 PLATFORMS  (curated providers from getCuratedProviders — 04.6-01)
2 PREMIUM    (mock paywall, locale-aware pricing)
3 READY      (recap card + Discover Lumi CTA — tap-isolated)
```

Storage steps unchanged (lang=1, country=2, platforms=3) for back-compat. The banner picker calls `completeStep(1)` + `completeStep(2)` on Save so the existing schema is fully populated.

## Detection banner copy

```
EN: "Detected: 🇩🇪 Deutsch UI · Germany"  + hint "Tap to change"
TR: "Algılandı: 🇩🇪 Deutsch arayüzü · Germany"  + hint "Değiştir"
```

Banner is a `<button>` (keyboard-focusable, ≥44pt touch target, frosted-glass styling with backdrop-filter blur).

## Bottom-sheet picker UX

- Slides up from bottom (translateY transition, 240ms).
- Backdrop dim + click-to-close (draft discarded).
- Two sections: Language (8 rows) + Country (31 rows).
- Single shared search input with 80ms debounce. Accent-fold (Turkish ı→i + NFD diacritic strip).
- Draft state — only commits on Save. Save calls `setLocale({lang, country})` (which fires `window.i18n.setLanguage` for live re-render) + `completeStep(1)` + `completeStep(2)`.
- Country change invalidates `state.providers` cache so the Platforms slide refetches via `getCuratedProviders` (04.6-01) with the new region.

## S4 Ready CTA fix — defense in depth

Three layers:

1. **Listener scoping.** `readyCta.addEventListener('click', ...)` with `e.currentTarget !== readyCta` guard. No slide-body or document-level click handler.
2. **Swipe block.** `touchend` short-circuits when `state.slide === 3` (was `=== 5` in old 6-slide enum). Both back-swipe and advance-swipe disabled on Ready.
3. **CSS pointer-events.** `.onb-slide-ready > *:not(.onb-cta-ready) { pointer-events: none }` ensures decorative children (recap card, hero title, spacers, confetti pieces) cannot receive taps. `.onb-cta-ready { pointer-events: auto; z-index: 2 }` opts back in.

## Deferred Issues

**Profile settings panel parity (deferred to Phase 5).**
The plan asked for post-onboarding locale + country changes via profile settings. `src/features/profile.js` (679 LOC) currently has auth + dropdown + ratings/stats helpers but **no Settings panel UI**. Adding a full Settings panel would be a significant feature lift outside the scope of "fix if missing/broken". Conservative path taken: the picker logic is reusable via `window.__onbOpenPicker()`, and the underlying `setLocale({lang, country})` API in `src/lib/locale.js` already triggers `window.i18n.setLanguage` for live re-render. Phase 5 will surface a Profile → Settings tab that calls the same picker.

**Profile re-render hook.** Confirmed working: `setLocale` invokes `window.i18n.setLanguage(next.lang)` which the existing i18n loader uses to re-render translated strings across all `data-i18n` consumers (no event bus required).
