<objective>
Reduce onboarding friction. The current 6-slide flow (Welcome → Language → Country → Platforms → Premium → Ready) has redundant manual choices: r7 already auto-detects language + country from navigator. Replace the two dedicated slides (S2 Language, S3 Country) with a single confirmable detection banner inline on S1 Welcome. Result: 6 → 4 slides.

Also fix the S6 (now S4) Ready-slide CTA bug — the r5 tap-anywhere-advances handler is too greedy, causing accidental advances when the user taps confetti or anywhere on the slide body. Only the explicit "Discover Lumi" CTA button should advance.

Also verify the Profile settings page can change language + country post-onboarding (existing surface; fix if missing/broken).

Purpose: Phase 4.6-CONTEXT calls out onboarding friction as a store-launch blocker. Auto-detection accuracy from r7 makes the manual confirm slides redundant for most users; power users still need an escape hatch via the inline picker.

Output: Refactored onboarding state machine + slide builders, new detection banner UX, bottom-sheet picker, S4 CTA fix, profile settings parity, and updated tests.
</objective>
