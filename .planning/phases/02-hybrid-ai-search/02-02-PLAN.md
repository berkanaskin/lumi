    Create Edge Function at `api/search.js` implementing the hybrid search (embedding + LLM fallback). This is the core Phase 2 differentiator.

    **Function signature:**
    ```
    POST /api/search
    Body: { query, userId, limit = 20 }
    Returns: { results, source, confidence, diversity }
    ```

    **Implementation steps:**

    1. **Validate input:**
       - Return 400 if query is empty or not a string
       - Ensure userId is provided (for personalization in Plan 03)
       - Set limit to max 20 results

    2. **Generate embedding for query:**
       ```javascript
       const embeddingResult = await embedMany({
         model: openai.embedding('text-embedding-3-small'),
         values: [query],
       });
       const queryEmbedding = embeddingResult.embeddings[0];
       ```
       - Use dimensions 512 (from EMBEDDING_CONFIG)
       - Log this call to api_metrics: {type: 'embedding', query, timestamp}

    3. **Vector search in Firestore:**
       ```javascript
       const snapshots = await db
         .collection('movie_embeddings')
         .findNearest('embedding', queryEmbedding, {
           limit: 20,
           distanceMeasure: 'COSINE',
         })
         .get();
       ```
       - Filter results by confidence threshold (0.75 per EMBEDDING_CONFIG)
       - Calculate avgScore from similarity scores
       - Log: {type: 'embedding', query, resultCount, similarity: avgScore, timestamp}

    4. **Confidence check:**
       - If avgScore > 0.80 (high confidence): Return embedding results immediately
         ```javascript
         return res.json({
           results: candidateDocs.map(doc => ({...})),
           source: 'embedding',
           confidence: avgScore,
         });
         ```

    5. **LLM fallback for low confidence:**
       - If avgScore <= 0.80 or no results:
         ```javascript
         const { generateObject } = await import('ai');
         const { z } = await import('zod');

         const llmResult = await generateObject({
           model: openai('gpt-4o-mini'),
           prompt: `User is searching for: "${query}". Suggest 10 movie/TV show TMDB IDs that match this request.`,
           schema: z.object({
             tmdbIds: z.array(z.number()),
             reasoning: z.string(),
           }),
         });
         ```
       - Fetch movies from TMDB by IDs
       - Log LLM call: {type: 'llm', query, fallbackReason: 'embedding_low_confidence', timestamp}
       - Generate embeddings for new content (for future queries)
       - Return LLM results with source: 'llm', confidence: 0.60

    6. **Error handling:**
       - Catch embedding generation errors → return 500
       - Catch Firestore errors → return 500
       - Catch LLM errors → return 500
       - All errors logged to console

    7. **Response format:**
       ```javascript
       {
         results: [
           {
             tmdbId: number,
             title: string,
             year: number,
             genres: string[],
             poster: string,
             rating: number,
           },
           ...
         ],
         source: 'embedding' | 'llm',
         confidence: 0.0-1.0,
         timestamp: ISO string,
       }
       ```

    **Key design decisions:**
    - Confidence threshold: 0.80 (from research, standard for content recommendations)
    - LLM model: gpt-4o-mini (cheaper than gpt-4, proven for content)
    - Return limit: 20 results (Plan 03 handles pagination)
    - Metric logging: Every call logged for cost monitoring

    Based on research pattern: api/search.js code example from 02-RESEARCH.md lines 544-656.

  <action>
    Create Edge Function at `api/cost-dashboard.js` for admin cost monitoring. This endpoint is read-only and shows metrics for understanding API spending.

    **Function signature:**
    ```
    GET /api/cost-dashboard
    Headers: Authorization: Bearer {Firebase token}
    Returns: { period, calls, costs, alerts, trend }
    ```

    **Implementation steps:**

    1. **Authentication (admin-only):**
       ```javascript
       const token = req.headers.authorization?.split(' ')[1];
       if (!token) return res.status(401).json({ error: 'Unauthorized' });

       const decodedToken = await admin.auth().verifyIdToken(token);
       if (!isAdmin(decodedToken.uid)) {
         return res.status(403).json({ error: 'Forbidden' });
       }
       ```
       - User must have admin: true in Firestore profile
       - Use Firebase Admin SDK (already available)

    2. **Calculate date range:**
       ```javascript
       const now = new Date();
       const monthStart = new Date(now.getFullYear(), now.getMonth(), 1);
       ```

    3. **Query metrics from Firestore:**
       ```javascript
       const metrics = await db
         .collection('api_metrics')
         .where('timestamp', '>=', monthStart)
         .get();
       ```

    4. **Aggregate metrics:**
       ```javascript
       const embeddingCalls = metrics.docs.filter(m => m.data().type === 'embedding').length;
       const llmCalls = metrics.docs.filter(m => m.data().type === 'llm').length;
       const totalCalls = embeddingCalls + llmCalls;

       // Cost calculation (from COST_CONFIG)
       const embeddingCost = (embeddingCalls / 1_000_000) * 0.02;  // $0.02 per 1M tokens
       const llmCost = (llmCalls * 500 / 1_000_000) * 0.15;       // Assume 500 tokens/query
       const totalCost = embeddingCost + llmCost;
       ```

    5. **Generate alerts:**
       ```javascript
       const alerts = [];

       if (totalCalls === 0) {
         alerts.push({ level: 'info', message: 'No API usage yet.' });
       }

       const llmRatio = totalCalls > 0 ? llmCalls / totalCalls : 0;
       if (llmRatio > 0.25) {
         alerts.push({
           level: 'warning',
           message: `LLM fallback ${(llmRatio * 100).toFixed(1)}% — embedding quality may need retraining`,
         });
       }

       if (totalCost > COST_CONFIG.monthlyBudgetAlert) {
         alerts.push({
           level: 'alert',
           message: `Monthly spend $${totalCost.toFixed(2)} — approaching budget`,
         });
       }
       ```

    6. **Calculate 7-day trend (sparkline data):**
       - Query metrics from last 7 days
       - Group by day
       - Calculate daily LLM fallback ratio
       - Return array of {date, ratio} for chart

    7. **Response format:**
       ```javascript
       {
         period: { start: monthStart, end: now },
         calls: {
           embedding: 2847,
           llm: 312,
           total: 3159,
           ratio: 0.90,  // embedding percentage
         },
         costs: {
           embedding: "18.50",
           llm: "2.10",
           total: "20.60",
           estimatedAnnual: "247.20",
         },
         alerts: [
           { level: 'info', message: '...' }
         ],
         trend: [
           { date: '2026-03-14', llmRatio: 0.18 },
           ...
         ],
       }
       ```

    8. **Error handling:**
       - Return 401 if not authenticated
       - Return 403 if not admin
       - Return 500 if Firestore query fails
       - Graceful empty state (no metrics yet)

    Based on research pattern: api/cost-dashboard.js example from 02-RESEARCH.md lines 362-412.
