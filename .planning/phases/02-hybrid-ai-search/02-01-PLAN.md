  <action>
    Create Edge Function at `api/embeddings.js` for batch embedding generation. This function:

    1. Accepts POST request with optional `limit` (default 50) and `version` (default 'v1')
    2. Fetches movies from Firestore without embeddings (or with older version)
    3. Generates embeddings in batches using OpenAI text-embedding-3-small
    4. Stores with versioning: `embedding_v1`, `embedding_v2`, etc.
    5. Logs metrics to `api_metrics` collection for cost tracking
    6. Returns summary: {processed: N, embeddings_generated: N, newVersion: 'v1'}

    Implementation requirements:
    - Import: `import { embedMany } from 'ai';` and `import { openai } from '@ai-sdk/openai';`
    - Use Firestore Admin SDK (already available per Phase 1)
    - Generate text from: `${movie.title} ${movie.year} ${movie.description} ${movie.genres.join(' ')}`
    - Batch size: 50 movies per run (cost control)
    - For each embedding generated, log to Firestore:
      ```javascript
      await db.collection('api_metrics').add({
        type: 'embedding',
        operation: 'generation',
        batchSize: 50,
        timestamp: new Date(),
        version: 'v1',
      });
      ```
    - Store embedding with metadata:
      ```javascript
      batch.update(movieRef, {
        embedding_v1: embeddingResult.embeddings[idx],
        embedding_model: 'text-embedding-3-small',
        embedding_version: 'v1',
        embedding_generated_at: new Date(),
      });
      ```
    - If movie already has embedding, skip (don't regenerate)

    Error handling:
    - Return 400 if no movies to process
    - Return 500 if embedding generation fails with detailed error
    - Log failures to console

    Security:
    - No auth required (internal Vercel function, private by default)
    - Can be called by cron jobs or manually

    Based on research pattern: api/embeddings.js code example from 02-RESEARCH.md lines 248-300.
  </action>

    // In existing TMDBService or new EmbeddingService class
    async generateEmbeddings(limit = 50, version = 'v1') {

        method: 'POST',
        headers: { 'Content-Type': 'application/json' },

        method: 'POST',
        headers: { 'Content-Type': 'application/json' },
