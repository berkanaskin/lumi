<objective>
Build Pair Mode: two real accounts pair by a 6-digit code into a persistent relationship, and the
AI returns titles neither has seen and both would likely enjoy.

Pairing must be auth-real (anon users are prompted to sign up — Pair Mode is the one feature that
needs two genuine identities). One user generates a short-lived 6-digit code; the other redeems it;
the server writes a persistent `pairs/{pairId}` doc holding both UIDs. Recommendations call
`api/gemini.js feature=pair`, intersecting both taste profiles (from seen.js), excluding the union
of both seen sets, and favoring titles available on platforms both own.

TDD: `tests/pairing.test.js` (code generate/redeem, TTL expiry, persistent pair, reject anon) and
`tests/pair-mode.test.js` (dual-seen exclusion, shared-platform preference, premium gate, anon→signup prompt) first.
</objective>
