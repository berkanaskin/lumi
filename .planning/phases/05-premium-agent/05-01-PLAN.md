<objective>
Build the entitlement + free-tier gating foundation. This plan makes "premium vs free" a real,
server-enforced concept the other four plans build on.

Three pillars:
1. **Identity** — silent Firebase Anonymous Auth so every user (guest included) has a stable UID.
   Signup/login upgrades the anon user via `linkWithCredential` so the UID (and all its
   Firestore data: usage, premium flag, migrated favorites) survives.
2. **Entitlement** — `src/lib/entitlements.js` is the single read path: `isPremium()` reads
   Firestore `users/{uid}.premium`, mirrored to localStorage for guests/offline. `setPremiumMock()`
   is the dev-only writer (Phase 6 replaces with the RevenueCat webhook).
3. **Gating** — `api/gemini.js` verifies the Firebase ID token, atomically increments
   `users/{uid}/usage/{localDate}.count`, and returns 429 on the 6th free query. Premium bypasses.

TDD: write `tests/entitlements.test.js`, `tests/usage.test.js`, `tests/gemini-quota.test.js`
FIRST (pure logic — local-date computation, increment, reset boundary, premium bypass, 429 shape),
then implement until green. Existing 387-test suite must stay green.
</objective>
