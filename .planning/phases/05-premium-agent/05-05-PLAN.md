<objective>
Build the notification layer: an in-app inbox plus the two cron-driven proactive features
(Smart Notifications + Evening Assistant). Real push (APNs/FCM) is Phase 6 — Phase 5 delivers the
detection logic and surfaces events in-app, with an event schema that maps cleanly onto push later.

`detect-changes` (daily, premium-only) diffs each premium user's watchlist: a platform-set change
(read via the Phase 4.6 cost-aware SA cache, prior set stored per item) or a series gaining a new
`next_episode_to_air` emits an inbox event. `evening-assistant` runs hourly and processes only the
timezone buckets whose local time is 20:00, writing 3 AI-personalized titles per user. The same
`tz` field set in 05-01 drives both local-20:00 delivery and the free-cap local-midnight reset.

TDD: `tests/notif-store.test.js`, `tests/detect-changes.test.js` (platform diff, episode diff,
premium-only scope, cache-first), `tests/evening-assistant.test.js` (tz-bucket selection at 20:00,
3-title output) first.
</objective>
