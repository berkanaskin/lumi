</domain>

<decisions>
## Implementation Decisions

### A. Streaming Providers (Turkey) — CRITICAL
- **Gain, Exxen, TV+, TOD** completely missing from streaming results
- **Apple TV, Google Play** may also be missing
- **HBO Max** shows but logo doesn't load
- **Duplicate results** appearing sometimes in streaming tiles
- Currently only Netflix, Disney+, Amazon Prime reliably show
- Root cause investigation needed: is this TMDB data limitation, Streaming Availability API limitation, or our code filtering them out?
- If API doesn't have Turkish platforms: consider hardcoding known Turkish streaming services with their deep-link URLs as a fallback
- Turkish streaming platforms and their services:
  - Gain (gain.tv) — Turkish originals
  - Exxen (exxen.com) — Turkish sports + originals
  - TV+ (tvplus.com.tr) — Turk Telekom platform
  - TOD (tod.tv) — beIN Media Group
  - BluTV (blutv.com) — Turkish streaming
  - Puhu TV (puhutv.com) — Free Turkish streaming

### B. Cinema Badge — UI REDESIGN
- Current "Su an sinemalarda" badge is ugly and hard to notice
- Must be visually distinctive — eye-catching but integrated into the design
- Should stand out on the poster without looking cheap
- Consider: gradient badge, animated pulse, or ribbon-style overlay

### C. Search/Discover Screen — REDESIGN WITH STITCH
- Entire search/discover screen needs redesign
- "Gunun Onerisi" (daily recommendation) feature MUST stay
- AI search (text input + "Oner Bana" button) still not working properly
- The layout, spacing, and visual hierarchy need rework
- Use Stitch MCP tool for design generation if available
- Mood chips and era chips should feel premium, not generic

### D. Favorites/Watchlist — BUG FIX
- "Begendiklerim" (Liked) not working properly
- "Izlediklerim" (Watched) not working properly
- Need to trace the full flow: like button → localStorage → favorites page render

### E. Profile — CUSTOMIZATION
- When user logs in via Gmail, their Google name/photo is auto-set — this is OK as DEFAULT
- But user MUST be able to change display name (custom nickname)
- User MUST be able to change avatar (pick from presets or upload)
- Changes should persist to Firebase user profile
- "Izlenen Film" and "Toplam Sure" stats — evaluate purpose:
  - If we keep: must be meaningful (track actual watched content)
  - If we remove: replace with something useful (like genre preferences or activity)
- Profile page general polish needed

### F. Code Cleanup
- Remove src/pages/search-results.js (search page was removed)
- Remove desktop CSS (sidebar, desktop layout — mobile only app)
- Clean up .claude/worktrees/ (4 old agent worktrees)

### Claude's Discretion
- Technical approach to investigate Turkish streaming platform coverage
- Cinema badge visual design
- Search/discover layout composition
- How to implement profile name/avatar editing (Firebase updateProfile vs Firestore)
- Whether to keep or remove watch stats

</decisions>

## Specific Ideas

- For Turkish streaming: check if TMDB /watch/providers endpoint returns Gain/Exxen/TOD for Turkish content. If not, build a manual mapping.
- For cinema badge: use CSS gradient + small icon (popcorn/ticket emoji) + date
- For search redesign: look at Letterboxd and IMDb mobile search for inspiration
- For profile: Firebase Auth has updateProfile(displayName, photoURL) — use that + Firestore for extended profile data
- For avatar: provide 10-15 preset avatars (movie-themed icons) + option to use Google photo

</specifics>
