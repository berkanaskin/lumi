# Phase 03.2 Plan 01: Favorites/Watchlist localStorage Key Fix Summary

Fixed the reader/writer key mismatch (`favorites`/`watchlist` vs `liked_items`/`watchlist_items`) plus item-shape mismatch (`item.poster`/`item.type` vs `item.poster_path`/`item.media_type`) that caused both Beğendiklerim and İzlediklerim screens to render empty.

## What Changed

- **New helper** `src/features/favorites-storage.js` exporting `loadFavoritesItems("liked" | "watched")` — reads canonical keys, performs one-time legacy migration, de-dups by id, removes legacy key, safe-parses corrupt JSON.
- **`src/main.js`** imports the helper and exposes it as `window.loadFavoritesItems` so the inline script in `index.html` can use it.
- **`index.html` `loadFavoritesList`** now delegates to the helper (with a graceful inline fallback) and renders using `item.poster_path` / `item.media_type`.
- **Tests** `tests/favorites-storage.test.js` — 7 cases covering both list types, migration, de-dup, empty state, corrupt JSON.
